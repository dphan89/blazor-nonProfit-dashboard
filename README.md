# Nonprofit Finance Dashboard — Student Project

Built a functional Blazor dashboard prototype using C#, HTML, CSS, and SQL, with working navigation and core nonprofit finance features.
Features include tracking donations, expenses by category, and donor records through a multi-page Blazor interface. 
The project uses a SQL Server database and Entity Framework-based data access.
